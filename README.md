# pico-scoreboard
Currently this project has two components:
1. Software to analyze the logic signal used by the Nevco 2-MC scoreboard controller and dump a bitstream
2. **(Very Work in progress)** Program to use a Raspberry Pi Pico 2 to simulate a Nevco 2-MC scoreboard controller

## Why?
Why not? I thought reverse engineering the scoreboard at work would be a fun and educational hobby project to spend my free time on.
